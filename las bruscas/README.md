# Las Bruzcas - Destino Único

## Descripción
Proyecto de página web para "Las Bruzcas", un destino único ubicado en Dolores, sobre la Ruta 2. Este proyecto presenta una estética elegante y detallada, orientada a mostrar la identidad, historia y masterplan del lugar.

## Estructura del Proyecto
- `las-bruzcas.html`: Documento principal HTML que contiene toda la estructura, estilos y contenido de la landing page.

## Secciones Principales
- **Hero**: Presentación visual inmersiva con estadísticas clave.
- **Concepto**: Explicación de la visión y diseño del proyecto.
- **Pilares**: Los fundamentos que sostienen la propuesta de Las Bruzcas.
- **Masterplan**: Diagrama y layout de los sectores y ubicación.
- **Historia**: Cronología y legado del lugar.
- **Inversión**: Información sobre sectores clave y oportunidades.
- **Identidad Visual**: Logos, cartelería y aplicaciones de la marca.

## Tecnologías Utilizadas
- HTML5 Semántico
- CSS3 (Variables, Grid, Flexbox, gradientes, pseudo-elementos)
- Fuentes Web: Cormorant Garamond y Montserrat

## Uso
El proyecto es estático, por lo que puede ser visualizado abriendo el archivo `las-bruzcas.html` directamente en cualquier navegador moderno.
