La solución

CentraIA no es un chatbot. Es una plataforma.

La diferencia clave: la IA nunca es la fuente de verdad. Los humanos validan. La IA organiza y responde.

🏗️

Multiempresa

Cada organización tiene su propio entorno aislado. Los datos de Sancor nunca se mezclan con los del estudio.

👁️

Human In The Loop

La IA propone. Los supervisores aprueban. Nunca se convierte en fuente de verdad sin validación humana.

🧩

Modular

Cada organización activa los módulos que necesita. El core siempre es el mismo. Las apps de negocio son opcionales.

🔒

Gobernanza

Auditoría completa, versionado de documentos, trazabilidad de respuestas. Cada respuesta cita su fuente.

Productos

Los módulos del ecosistema

Sobre el core de CentraIA se montan aplicaciones de negocio verticales. Comparten usuarios, seguridad, IA y auditoría.

✓ En producción
🏛️

CentraIA Core

La plataforma base. Gestión documental con IA, RAG, chat conversacional, supervisores y administración multiempresa.

  • Carga y versionado de documentos
  • Chat con IA + citación de fuentes
  • Panel de supervisores HITL
  • Administración de organizaciones
  • Métricas y auditoría
✓ En desarrollo activo
🔬

LaborIA

Módulo de gestión de laboratorios clínicos integrado al ecosistema. Pacientes, muestras, resultados e informes con asistencia IA.

  • Gestión de pacientes y muestras
  • Resultados e informes automáticos
  • Consulta de protocolos con IA
  • Historial y trazabilidad
  • Usa el mismo motor IA del core
◐ Próximo

BrokerIA

Módulo para productores de seguros. Integración con Sancor Seguros, gestión de pólizas, automatización de cupones y altas AP.

  • Cupones de pago automáticos vía WhatsApp
  • Integración API Sancor (IBM API Connect)
  • Consulta de pólizas vigentes
  • Alertas de vencimiento
○ En planificación

EstudioIA

Lo que ya construimos

Del concepto a la realidad

No es una idea en papel. Es un proyecto con tecnología funcionando y casos de uso validados.

Infraestructura técnica

Core IA

Motor RAG operativo

Python 3.11 + FastAPI + Qdrant (Docker). SIMILARITY_THRESHOLD calibrado. Embeddings con Claude API.

Arquitectura

Multi-agent en VS Code

3 sesiones Claude Code paralelas: BACKEND, INGESTA, DEVOPS. Workflow desacoplado y escalable.

Automatización

Stack Sancor funcionando

Playwright + OpenWA en producción. Cupones descargados y distribuidos automáticamente.

Integración

IBM API Connect + Auth0

Aplicación registrada. APIs Generales y Siniestros activas. PoliciesIDS en gestión con Sancor.

Tecnología

El stack que lo hace posible

Tecnología de punta, sin vendor lock-in, desplegable en cualquier infraestructura.

🧠

Claude API

Motor de lenguaje. Respuestas, embeddings y agentes conversacionales.

🗄️

Qdrant

Base de datos vectorial. Búsqueda semántica sobre documentos.

⚡

FastAPI + Python

Backend del motor RAG. Alta performance, fácil de extender.

⚛️

React + Vite

Frontend moderno. Portal web y panel de administración.

🔗

Node.js + Express

Backend de integración. APIs, webhooks y conectores.

💬

OpenWA

Gateway WhatsApp self-hosted. Notificaciones y bot conversacional.

🤖

Playwright

Automatización web. Puente mientras las APIs no están disponibles.

🐳

Docker

Contenedores para Qdrant y servicios. Despliegue reproducible.
