Visión del Proyecto

Integrar el desarrollo de aplicaciones móviles y web en un ecosistema profesional. Buscamos transformar conceptos en sistemas reales mediante el dominio de tecnologías modernas, arquitecturas escalables y metodologías ágiles.

Ruta de Aprendizaje

Cada clase construye sobre la anterior. Seguí el hilo — cada concepto que aprendés hoy es un bloque del sistema que vas a construir mañana.

🗄️
2° Año CLASE 01

Backend con PHP & MySQL

El punto de partida. Variables, tipos de datos, operadores y decisiones en PHP. Conexión a MySQL con XAMPP, CRUD completo con formularios (Crear · Leer · Actualizar · Eliminar), estructura del lenguaje SQL, Primary Keys, Foreign Keys e integridad referencial. Acá nace la lógica de negocio de todo sistema.

Ir a la clase →
🔗
2° Año CLASE ESPECIAL

MySQL Avanzado: FK & CRUD Relacional

Lo que más costó entender: cómo relacionar tablas de verdad. Claves foráneas (FK), integridad referencial profunda, UPDATE con fechas automáticas y el CRUD de segundo nivel donde los datos están vivos y conectados.

Ir a la clase avanzada →
📋
2° Año CLASE REPASO

Repaso Total MySQL

Consolidación completa antes de pasar al frontend móvil. Tipos de datos correctos, TIMESTAMP paso a paso, CRUD con una sola tabla, relaciones 1:N y N:M, claves foráneas, errores comunes y quiz de verificación interactivo.

Ir al repaso →

💡 El servidor PHP que construiste en clase 01 va a ser la API que consume la app móvil. El backend no cambia — solo cambia quién lo llama.

📱
2° Año CLASE 02

Apps Móviles con React Native

Con el backend funcionando, damos el salto al frontend móvil. React Native + Expo nos permiten crear apps iOS y Android reales. El servidor PHP del paso anterior responde en JSON — la app lo consume con fetch().

Ir a la clase →

🌐 Con la app móvil funcionando, el siguiente paso es el frontend web profesional. Next.js nos permite construir un sistema Full Stack real — API REST + interfaz — usando el mismo stack que usan los equipos profesionales hoy.

⚡
2° Año CLASE 03

Full Stack: Sistema de Reservas con Next.js

El stack profesional completo: Next.js 15, Prisma ORM, Tailwind CSS, Framer Motion y shadcn/ui. Construimos un MVP real de reservas para restaurante — con API REST, base de datos, formularios validados con Zod y animaciones de producción.

Ir a la clase →

🏗️ Antes de seguir construyendo, necesitás aprender a planificar como un arquitecto. Separar el rol de quien diseña del rol de quien ejecuta cambia completamente cómo se usa la IA para construir software.

🧠
2° Año CLASE 04

IA como Arquitecto de Software

Aprendé a separar el rol de quien diseña del rol de quien ejecuta. GPT como arquitecto (planifica, define el core y delimita el MVP) y Antigravity como ejecutor (implementa sin tomar decisiones de diseño). Caso real: agencia de autos.

Ir a la guía →

🚀 En 3° año vas a construir la web app que comparte la misma API que la app móvil de 2°. PHP → JSON → React Native (móvil) y React (web) al mismo tiempo. Un solo backend, dos frontends.

🏗️
3° Año CLASE 01

Arquitectura & MVP — De la Idea al Sistema Real

Con las bases del backend y el frontend móvil claras, en 3° año estructuramos el sistema completo: visión de producto, épicas, arquitectura monolítica, y código React + Node + MySQL que funciona de verdad en producción.

Ir a la clase →

🧠 Con el sistema base funcionando, el siguiente nivel es hacerlo inteligente. Integración de LLMs, bases vectoriales y toma de decisiones basada en datos.

3° Año CLASE 02

IA para la Toma de Decisiones

Cómo construir un sistema de toma de decisiones basado en IA usando documentación interna. Implementación de Retrieval-Augmented Generation (RAG), Embeddings y bases de datos vectoriales.

Ir a la clase →

🎨 El backend y la IA necesitan una interfaz extraordinaria. Uso de Tailwind CSS, animaciones fluidas y co-diseño con IA para impactar desde la pantalla.

Diseño de Interfaces de Usuario (UI) con IA

Cómo elevar la estética de cualquier aplicación a nivel producción. Integración de Tailwind CSS, animaciones interactivas y frameworks modernos guiados por Inteligencia Artificial.
